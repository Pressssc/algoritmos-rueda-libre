Asistente de Taquilla Rueda Libre 

Este repositorio contiene el desarrollo del sistema de taquilla y cotización para ruedañibre

repositorio

`algoritmos/`: Archivos con extensión `.psc` ejecutables en PSeInt.
   `01_cotizacion_basica.psc`: Algoritmo para calcular el alquiler individual por horas.
   `02_cotizacion_recorrido.psc`: Algoritmo para cotizar recorridos guiados con cálculo de anticipo (30%) y saldo.
   `03_cuenta_grupo.psc`: Algoritmo integrado para calcular la cuenta del grupo, aporte voluntario del 10% y división de cuota redondeada a la centena.
`diagramas/`: Diagramas de flujo exportados en formato PNG.
`bitacora.md`: Documentación completa del proceso de diseño, análisis de algoritmos, tablas EPS y pruebas de escritorio.

como ejecutar 

1. Abre la aplicación de pseint
2. En la configuración del lenguaje (Opciones -> Opciones del Lenguaje / Perfil), asegúrate de usar un perfil que exija la definición explícita de variables.
3. Dirígete a `Archivo` -> `Abrir` y selecciona cualquiera de los archivos `.psc` ubicados en la carpeta `algoritmos/`.
4. Haz clic en el botón de Ejecutar para probar el programa o en dibujar diagrama de flujo para visualizar la estructura gráfica.
